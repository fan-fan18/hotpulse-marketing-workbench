# 创作风格与语调页 · 使用说明

一条热点要出多个版本的文案给运营挑，每个版本由一个「创作风格」驱动；「语调预设」则决定这次的口吻基调。这一页就是维护这两份清单的地方。

入口：`admin.html#/styles`

---

## 一、创作风格

每个风格由 **名称 + 创作要求** 两段组成，例如：

| 名称 | 创作要求 |
| --- | --- |
| 热点借势 | 先接住热点情绪，再自然过渡到商品，重体验感。 |
| 促销导向 | 突出价格钩子与紧迫感，重转化，价格必须来自素材。 |
| 互动话题 | 用提问和共鸣把读者拉进评论区，互动引导要具体。 |
| 深度种草 | 讲清使用场景和细节体验，卖点落到具体感受上。 |

能做的操作：**新增 / 修改 / 删除 / 上移 / 下移**。列表左侧的序号就是工作台里的候选版本顺序，页面底部会实时显示「当前 N 个风格 → 产出 N 个候选版本」，并给出工作台卡片形态的效果预览。

**至少保留一个风格。** 删到只剩一个时再点删除，会被拦住并弹出说明：

> 不能删掉最后一个创作风格
> 至少要保留一个风格，工作台才有生成文案的依据。
> 如果确实要换风格，可以：① 直接改这个风格的名称与创作要求；② 先新增一个新风格，再把旧的那个删掉。

---

## 二、语调预设

一组标签（默认：热点借势、促销导向、互动话题、日常分享），可增删。它有两个作用：

1. 在工作台 Step 4 的「主打语调」下拉里作为可选项出现；
2. 选中后写进素材的「主打语调：」一行，作为素材的一部分传给模型。

同样至少保留一个——素材里的 `{{语调}}` 需要有个值，不然会变成空行。

---

## 三、它和工作台是怎么串起来的

```
后台「创作风格与语调」保存
        ↓ 服务端 / 本机浏览器（三级配置）
工作台 Step 4
        ↓ 勾选的每个风格各编译一次提示词（含该风格的「风格要求」）
        ↓ 各调用模型一次
   候选版本 ×N（标题就是风格名）
```

所以新增一个风格并保存后，工作台生成文案时就会多出一个对应风格的候选版本；新增一个语调并保存后，工作台的「主打语调」下拉里就能选到它。

> 提示：工作台默认勾选全部风格。风格多了以后，可以在工作台里取消勾选不参与本次生成的风格。

## 五、本轮顺带修掉的两个真实缺陷

1. **输入被吞**：原来给名称/要求输入框挂了 `blur → 整页重渲染`，用户点到下一个字段时 DOM 会被重建，正在输入的内容会丢（表现为"最后一行创作要求怎么填都存不上"）。现在改成输入时只局部刷新统计文字与预览卡片，列表 DOM 保持稳定。
2. **语调与风格要求传不到模型**：默认素材模板里没有 `{{语调}}` / `{{创作风格}}` / `{{风格要求}}` 这几个占位符，导致这两项配置形同虚设。已把默认素材模板补全为包含热点素材、商品素材、本次要求（语调 / 创作风格 / 风格要求 / 字数 / 表情强度 / 可用金额）的完整骨架。

> 注意：第 2 条修的是**默认值**。如果你之前已经保存过自己的素材模板，那份模板不会被覆盖（配置读取时"已保存的值优先"）。想要新的默认骨架，可以到「提示词与模板」页把素材模板改一下，或恢复该区块默认。
