# 数据模板：每个数据入口都能导出填写、导入校验

> 适用版本：2026-10 自建数据实跑版  
> 相关文件：`assets/js/core/templates.js`（模板定义与校验）、`assets/js/admin/admin-templates.js`（弹窗）、`data/seed/`（填写好的范例）

## 1. 这个功能解决什么问题

运营不改代码也要能往系统里灌数据。以前的痛点是：每加一件商品、每加一个订阅源、每调一条创作风格，都要找研发改 `data.js`。

现在每个数据入口都自带一套**填写模板**：

- **下载空白模板**：只有表头，照着自己填；
- **下载示例模板**：表头 + 一两行示范写法（示范行是通用写法，不是业务数据，填之前删掉）；
- **导入**：选文件 → 先逐行校验出报告 → 你决定是否写入；
- **导出当前数据**：把配置里这一块导成文件，改完再导回来。

写入只改**编辑区**，真正落库仍然走底部「保存配置」（或 `Ctrl + S`）。所以导入错了可以直接「撤销未保存改动」。

## 2. 七个数据入口

| 入口 | 在哪一页 | 格式 | 一行表示 | 备注 |
| --- | --- | --- | --- | --- |
| 商品库 | 商品库 | CSV / JSON | 一件商品 | 表头固定：名称、售价、原价、品类、卖点、图标 |
| 抓取来源 | 抓取来源 | CSV / JSON | 一个订阅源 | 只处理自定义源；内置热榜只能停用不能删 |
| 创作风格 | 创作风格与语调 | CSV / JSON | 一个风格 | 至少保留一个 |
| 语调预设 | 创作风格与语调 | CSV / JSON | 一个语调标签 | 至少保留一个 |
| 评测用例 | 评测台 → 用例管理 | CSV / JSON | 一条用例 | 热点ID + 商品编号 + 话题 + 语调 |
| 提示词与模板 | 提示词与模板 | 仅 JSON | 整块提示词 | 多行文本，用 JSON 更好维护；密钥不会出现在文件里 |
| 模型与接入 | 模型与接入 | 仅 JSON | 一份模型设置 | 同上，`apiKey` 不会被导出 |

每页区块标题右侧的「填写模板」按钮就是入口；评测台的入口在用例管理视图的工具条上。

## 3. 字段与规则

### 3.1 商品库（`名称,售价,原价,品类,卖点,图标`）

- 名称必填；
- 售价必须 > 0；
- 原价留空按售价计；填了就必须 ≥ 售价，否则**这一行**报错（不会写进去）；
- 卖点用顿号分隔，建议 2–4 个（超出只提醒，不拦截）；
- 图标留空默认 🛍️；
- 编号自动生成，从 `p1` 起递增，不会和已有重复。

### 3.2 抓取来源（`名称,地址,类型,启用,备注`）

- 地址必须是 `http://` 或 `https://` 开头的完整地址，否则这一行报错；
- 类型 `feed` / `json` / `auto`；
- 同地址重复导入是「更新」不是「新增」；
- 导入的源一律是**自定义源**（可停用、可删除），影响不到内置热榜。

### 3.3 创作风格（`顺序,名称,创作要求`）/ 语调预设（`名称`）

- 导入是**整块替换**：文件里有什么就是什么，顺序按「顺序」列排；
- 名称重复、名称为空、创作要求为空都会被拦；
- 删到 0 个会被拦住（至少要保留一个）。

### 3.4 评测用例（`名称,热点ID,商品编号,话题标签,语调,表情强度,参与本轮`）

- 热点ID：热点池条目的编号（形如 `sn_...`），工作台 Step 1 或热点池里能拿到；
- 商品编号：`p1`、`p2` 这样，用顿号或逗号分隔，最多 3 件，第一件是主推；
- 商品编号不存在会**报错**（不会悄悄跳过）；
- 语调必须是语调预设里已有的名称，否则报错；
- 表情强度 0 / 1 / 2；参与本轮填「否」则导入后不勾选。

### 3.5 提示词与模板 / 模型与接入（JSON）

- 导入只覆盖文件里**出现过**的字段，没写的保持原样；
- 提示词里 `{{占位符}}` 原样保留，不认识的占位符也不会被清空；
- 模型文件里即使带了 `apiKey` 也不会导入（会有提醒）。

## 4. 导入前的校验报告

选完文件先出报告，不会直接写：

```
共 4 行数据：通过 3 行，有问题 1 行。
行号        原因
第 2 行     售价必须是大于 0 的数字（当前：-9）
```

这时可以：

- **只写入通过校验的 N 行**；
- 或者关掉弹窗，改好文件再导一次（原有配置一点没动）。

文件本身坏掉（表头不对、JSON 语法错、找不到数组）会直接拦住，并说明「当前表头 / 要求的表头」。

## 5. CSV 细节

- 带 BOM，Excel / WPS 直接打开不乱码；
- 支持引号包裹的字段、字段内部含逗号、字段内部换行、`""` 转义；
- 表头允许有多余列（忽略），但必需列不能少。

## 7. 一句提醒

模板只负责「把数据搬进来」，不替你判断业务。价格、卖点、合规都是人的责任——所以每个入口都保留了「先看报告再决定」。
