# 商品库页（只读版）· 使用说明

商品库原本写死在代码里，现在搬到后台由运营维护。**本段先做只读浏览部分**：统计、搜索、筛选、排序，以及表格 / 卡片两种视图。新增与编辑、批量操作、导入导出留到后续段落。

入口：`admin.html#/products`

---

## 一、三个区块

### 1. 统计概览

| 指标 | 口径 |
| --- | --- |
| 商品总数 | 当前列表件数（未筛选时等于整个商品库） |
| 品类数 | 按品类字段去重 |
| 价格区间 | 当前列表的最低价–最高价（并给出平均售价） |
| 平均折扣率 | 按 `(1 − 售价 ÷ 原价)` 逐件计算后取平均 |

统计**跟随当前筛选结果变化**，卡片下方一行会说明这一点：未筛选时写着"未筛选时等于整个商品库"，筛过之后写着"统计随当前筛选结果变化"。这样列表和数字永远对得上，不会出现"看着 6 件、数字还是 20 件"的困惑。

### 2. 搜索、筛选与视图

- **搜索**：匹配名称、卖点、品牌、SKU、品类；搜卖点里的词（例如「烧水保温」）能找到对应商品；
- **品类筛选**：下拉里是商品库里实际出现过的品类；
- **排序**：默认（录入顺序）、价格从低到高、价格从高到低、按品类、折扣力度从大到小；
- **视图切换**：表格 / 卡片，随时切换，下方会写明"当前显示 N / M 件（卡片视图）"。

### 3. 商品列表

**表格视图**：商品（缩略图 + 名称 + 品牌/SKU）、品类徽章、售价、原价（带删除线）、折扣率、近 30 天销量、库存、卖点标签。

**卡片视图**：与工作台里看到的商品卡**同源**——两者都由 `HP.Products.cardHtml()` 这一段代码渲染，所以看到的是同样的图标、渐变底色、品类徽章、卖点标签、价格与划线价，以及近 30 天销量 / 转化率 / 库存。

工作台 Step 2 的推荐卡在同一张卡的基础上多了「匹配度」角标、「推荐理由」和「采纳并绑定」按钮——这是同一段渲染函数通过参数（`score` / `reason` / `actions`）扩展出来的，不是两份代码。

## 二、数据来源

商品数据走的是和其它配置一样的**三级读取**：服务端 → 本机浏览器 → 内置默认值。顶栏徽章会显示当前生效的是哪一级（本页统计概览下方也重复标注了一次，方便对照）。

启动 `node server/server.js` 打开后台时徽章是「服务端」；直接双击 `admin.html` 打开时是「本机浏览器」，商品库照样能正常浏览。

## 三、本次实测结果

`node tests/ui-products-tests.js` → **25 项通过 / 0 失败**（真实浏览器 + 真实服务端）

**验收 3 · 统计数字与列表实际内容对得上**

| 指标 | 页面显示 | 从表格明细反算 |
| --- | --- | --- |
| 商品总数 | 20 件 | 表格 20 行 = 商品库 20 件 |
| 品类数 | 7 个 | 表格里出现 7 个品类 |
| 价格区间 | ¥39–469 | 实际最低 ¥39、最高 ¥469 |
| 平均折扣率 | 47.8% | 明细重算 47.8% |

筛选「数码配件」后再比对：统计变为 6 件 / 1 个品类 / ¥39–429 / 44.8%，与筛选后的列表逐项一致。

**验收 2 · 搜索卖点里的词、筛选与排序**

- 先确认「烧水保温」这个词**只出现在卖点里、不在任何商品名里**（名称命中 0 件、卖点命中 1 件）
- 搜索该词 → 命中 1 件「恒温电热水杯 316 不锈钢 500ml」
- 品类筛选「数码配件」→ 6 件，全部属于该品类（与商品库里该类目数量一致）
- 价格升序 → 39 → 59 → 69 → 79 → 89 …；价格降序 → 469 → 429 → 369 → 359 → 299 …
- 按品类排序 → 服饰鞋包 → 户外运动 → 家居家纺 → 家用电器 → 美妆个护 → 食品生鲜 → 数码配件（同品类聚在一起，无穿插）

**验收 1 · 两种视图切换、卡片与工作台视觉一致**

- 切到卡片视图：20 张卡片、表格隐藏；切回表格：表格重新出现
- 后台卡片 DOM 与 `HP.Products.cardHtml(product)` 的输出**逐字节相同**（同源证明）
- 取同一件商品 p1 与工作台 Step 2 的卡片逐项比对：

| 对比项 | 结果 |
| --- | --- |
| 图标 | 两边都是 🧥 |
| 渐变底色 | 两边 thumb 背景完全相同 |
| 品类徽章 | 两边都是「服饰鞋包」 |
| 价格 / 划线价 | 两边都是 ¥299 / ¥599（50.1% OFF） |
| 卖点标签 | 两边都是同样的 3 个卖点 |
| 工作台额外内容 | 匹配度、推荐理由、采纳按钮（商品库只读卡片没有） |

- 三级来源：服务端下徽章「服务端」；`file://` 直接打开时徽章「本机浏览器」，商品库仍渲染出 20 件

## 四、这一轮顺带做的两件事

1. **抽出共享的商品卡渲染器**：原来商品卡写在工作台的 `app.js` 里，后台卡片视图要和它"长得一样"只能靠人肉抄一遍。现在统一到 `assets/js/core/products.js` 的 `cardHtml()`，工作台 Step 2 改成调用它，两边真正同源。顺带在这张卡上补了**品类徽章**（需求里点名要有），折扣率也从"取整"改成一位小数更准确。
2. **修掉服务端"首次运行"误报**：以前配置文件还不存在时，读取会把它当成"缺少 11 个区块"并提示运营。现在区分了"首次运行（新建）"与"确实缺了一段"两种情况，首次运行不再提示；同时把 `version` / `updatedAt` / `ui` 这三个内部键排除在"区块"之外，提示里只会出现真正的配置区块名。
