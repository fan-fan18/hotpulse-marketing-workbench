# HotPulse 热点引擎 · 电商媒体热点营销工作台（Web 原型 Demo）

从「新闻抓取」到「热点商品匹配」，再到「LLM 微博文案生成与审核发布」的全流程闭环原型。
面向电商运营与媒体采编：日常监控热点新闻 → 挑选匹配商品 → 一键生成多版本微博文案 → 人工审核后发布。

**技术约束**：不引第三方库、无构建步骤。前端是原生 HTML/CSS/JS，服务端是零依赖 Node（只用内置模块），
双击 `启动服务.bat` 就能跑起来。

---

## 快速开始

```bat
:: 方式一：双击（Windows）
启动服务.bat

:: 方式二：命令行
node server/server.js            :: 默认 8787 端口，可跟端口号参数
```

| 入口 | 地址 |
| --- | --- |
| 工作台（5 步流程） | http://localhost:8787/index.html |
| 配置后台（7 个配置页） | http://localhost:8787/admin.html |

不启动服务端也可以直接双击 `index.html` / `admin.html` 看界面，此时配置落在**本机浏览器**，
不会真的抓取外部站点；顶栏徽章会如实显示当前配置来自哪一级（服务端 / 本机浏览器 / 内置默认值）。

## 功能地图

**工作台（5 步闭环）**
1. 新闻抓取：热点列表、来源筛选、真实抓取（服务端模式下）
2. 建议匹配商品：系统按语义自动推荐热点-商品关联
3. 匹配商品：手动筛选与绑定商品库
4. 创作文案：每个「创作风格」独立跑一次，产出多个候选版本，带 Loading 与一键复制
5. 审核并发送：微博卡片预览、合规审核、模拟发布

**配置后台（7 页，与工作台共用同一份配置）**
- 配置总览、提示词与模板、创作风格与语调、模型与接入、商品库、抓取来源、评测台

**评测与自动返工**：机器校验 8 项（字数/话题标签/表情/广告法违禁词/编造价格/互动引导/排版符号/商品提及）
+ 模型评审四维打分 + 加权总分 + 自动返工（只把改了有用的问题送去返工，只接受改好的版本）。

```

```

## 部署

```bat
node server/server.js            :: 本机或服务器上启动
node tests/deploy-tests.js       :: 部署自检 23 项
```

- 监听地址、端口、密钥都可用环境变量配置：`PORT` / `HOST` / `HOTPULSE_API_KEY`
- 静态访问已收口：`data/`（含密钥字段）、`server/`、`tests/`、`scripts/`、`work/`、`outputs/` 一律 403
- 写入前自动备份上一版（`data/backups`，保留最近 10 份）；读取时缺失区块自动补默认值；关键内容为空拒绝写入

完整说明（局域网共享、Linux systemd、Nginx + HTTPS、公网部署前必须补的 7 个缺口）见
[`工程文档/部署指南.md`](工程文档/部署指南.md)。

## 边界说明

- 热点、商品、发布结果都是演示数据；公开热榜接口只适合原型演示，正式上线应改用官方开放平台或商业舆情服务，并遵守对方的爬虫协议与服务条款。
- 未配置密钥时模型走「本地模拟」，界面会明确标注"模拟输出，不代表真实模型效果"。
- Step 5 的「一键发送」是模拟发布；接真实微博开放平台需要写权限、token 续期、幂等重试与撤回机制。
- 公网部署前必须补：登录鉴权、密钥入环境变量、收紧 CORS、HTTPS、并发写、操作审计、发布通道。
